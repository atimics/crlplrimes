# Word Lists

`enable2k.txt` is the default lexicon for the haiku language-model prototype.
It is a Scrabble-like word-game list, not an official NASPA/NWL, Collins, or
Hasbro SCRABBLE dictionary.

Source:

- upstream repository: `https://github.com/BartMassey/wordlists`
- upstream file: `enable2k.txt.gz`
- downloaded source notes: `README-BartMassey-wordlists.md`
- downloaded ENABLE notes: `README-enable2k.txt`
- repository license: `LICENSE-BartMassey-wordlists.txt`

Reason for using ENABLE2K:

- the upstream notes describe it as a high-quality alternative to copyrighted
  official Scrabble dictionaries
- the ENABLE notes state that the list is plain ASCII and public domain
- the upstream repository explicitly does not ship SOWPODS/NASPA/Collins lists
  because of copyright concerns

Use this list for reproducible lexical gating. Use an official tournament list
only if the project obtains the appropriate license and records that provenance.
